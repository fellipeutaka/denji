# Denji

CLI tool for managing SVG icons in frontend projects — fetches from Iconify, converts to framework-specific components (React, Preact, Solid, Vue, Svelte, Qwik).

## Agent skills

### Issue tracker

Issues live in GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
